Redirect URL Endpoint For a static HTML site, redirects are typically handled at the server level. Below are common methods for setting up a redirect, depending on your hosting environment. **A. For Apache Servers (.htaccess file)** If your static site is hosted on an Apache server, you can create or edit a file named `.htaccess` in the root directory of your website. To redirect one specific URL to another: ```apache Redirect 301 /old-page.html /new-page.html ``` * `301` indicates a permanent redirect. * `/old-page.html` is the path to the page you want to redirect *from*. * `/new-page.html` is the path to the page you want to redirect *to*. To redirect an entire domain or a subdirectory: ```apache # Redirect an entire domain RedirectMatch 301 ^/(.*)$ https://www.topshelfservicepros.com/$1 # Redirect an old directory to a new one RedirectMatch 301 ^/old-directory/(.*)$ /new-directory/$1 ``` **B. For Nginx Servers (nginx.conf)** If your static site is hosted on an Nginx server, you'll need to modify your Nginx configuration file (often `nginx.conf` or a file within `sites-available`/`sites-enabled`). To redirect one specific URL to another: ```nginx location = /old-page.html { return 301 /new-page.html; } ``` To redirect an entire domain or a subdirectory: ```nginx # Inside your server block server { listen 80; server_name old-domain.com; # Or specific old URL # Redirect an entire domain return 301 https://www.topshelfservicepros.com$request_uri; # Or redirect a specific path location /old-directory/ { return 301 /new-directory/; } } ``` **C. HTML Meta Refresh (Less Recommended for Permanent Redirects)** While not ideal for SEO or permanent redirects, you can use a meta refresh tag within the `` section of an HTML file. This method is client-side and means the browser has to load the HTML page first before redirecting. Create a simple HTML file (e.g., `redirect.html`) with the following content: ```html Redirecting...

If you are not redirected automatically, follow this link to the new page.

``` * `content="0; url=..."` means redirect immediately (0 seconds) to the specified URL. * The `` tag helps search engines understand the correct, preferred URL. * The JavaScript fallback is for browsers that might ignore the meta refresh. **Which method to choose?** * **Server-side redirects (Apache .htaccess, Nginx config)** are preferred for permanent redirects (301) as they are more efficient, better for SEO, and transparent to the user. * **HTML Meta Refresh** should only be used if you have no server-side control, or for very temporary, client-side driven redirects.
