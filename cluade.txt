    <h2 id="services">1. Services Overview</h2>
    
    <p>The following services are created and ready for implementation:</p>
    
    <div class="service-card">
        <div class="service-name">governor.service</div>
        <div class="service-desc">Master orchestration service that manages all other components. Controls resilience, optimization, security, and resource monitoring.</div>
        <pre>
# Location: /etc/systemd/system/governor.service

[Unit]
Description=System Governor
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/project
ExecStart=/opt/project/governor.sh
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
        </pre>
    </div>
    
    <div class="service-card">
        <div class="service-name">security.service</div>
        <div class="service-desc">Security Enforcement Agent (SEA) that continuously monitors and fixes security issues.</div>

[Unit]
Description=Security Enforcement Agent
After=network.target

[Service]
Type=simple
User=root
ExecStart=/opt/project/security/sea_agent.sh

    <h2 id="local">2. Local Implementation</h2>
    
    <div class="steps">
        <h3>Complete Local Setup Instructions</h3>
        <ol>
            <li>Clone the repository:
                <pre>git clone https://github.com/peteywee/color-system.git
cd color-system</pre>
            </li>
            <li>Run the bootstrap script:
                <pre>chmod +x bootstrap/bootstrap.sh
./bootstrap/bootstrap.sh</pre>
            </li>
            <li>Verify installation:
                <pre>source ~/.bashrc
cwarn "This text should be yellow"
cerror "This text should be red"
csuccess "This text should be green"
creset</pre>
            </li>
            <li>Register systemd services:
                <pre>sudo cp security/security.service /etc/systemd/system/
sudo cp governor.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable governor.service security.service
sudo systemctl start governor.service security.service</pre>
            </li>
            <li>Configure PostgreSQL:
                <pre>./tools/install_postgres.sh
# Follow prompts for database user creation</pre>
            </li>
            <li>Setup GitHub integration:
                <pre>./tools/gh_setup.sh
# Follow prompts for GitHub authentication</pre>
            </li>
            <li>Configure Supabase and Vercel (if needed):
                <pre>./tools/install_supabase.sh
./tools/install_vercel.sh</pre>
            </li>
        </ol>
    </div>

    <h2 id="docker">3. Docker Implementation</h2>
    
    <h3>Dockerfile with Trixie/Bookworm Fallback</h3>
    <pre>
# Location: Dockerfile

ARG BASE_IMAGE=debian:trixie
FROM ${BASE_IMAGE}

# Install essential packages
RUN apt-get update && apt-get install -y \
    curl wget git jq bash sudo \
    nodejs npm \
    && rm -rf /var/lib/apt/lists/*

# Copy project files
COPY . /opt/project
WORKDIR /opt/project

# Run bootstrap with error handling
RUN chmod +x bootstrap/bootstrap.sh \
    && ./bootstrap/bootstrap.sh || \
    { echo "Trixie build failed, using Bookworm"; exit 1; }

# Default command
CMD ["/bin/bash"]
    </pre>
    
    <h3>Docker Build Script with Fallback</h3>
    <pre>
#!/usr/bin/env bash
# Location: build-with-fallback.sh

echo "[+] Attempting to build with Debian Trixie..."
docker build --build-arg BASE_IMAGE=debian:trixie -t color-bootstrap-trixie . && {
  echo "[✓] Trixie build succeeded."
  exit 0
}

echo "[!] Trixie build failed. Falling back to Bookworm..."
docker build --build-arg BASE_IMAGE=debian:bookworm -t color-bootstrap-bookworm .
    </pre>
    
    <h3>Docker Compose Setup</h3>
    <pre>
# Location: docker-compose.yml

version: '3.8'

services:
  color-system:
    build:
      context: .
      args:
        BASE_IMAGE: debian:trixie
    volumes:
      - ./data:/opt/project/data
    environment:
      - GIT_USER=${GIT_USER}
      - GIT_EMAIL=${GIT_EMAIL}
    restart: unless-stopped
    
  postgres:
    image: postgres:15
    environment:
      - POSTGRES_PASSWORD=${POSTGRES_PASSWORD:-postgres}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: unless-stopped
      
volumes:
  postgres_data:
    </pre>

    <h3>DigitalOcean Droplet Setup</h3>
    <pre>

ssh root@your_droplet_ip

# Install Git
apt update && apt install -y git

# Clone the repository
git clone https://github.com/peteywee/color-system.git
cd color-system

# Run the bootstrap script
chmod +x bootstrap/bootstrap.sh
./bootstrap/bootstrap.sh

# Register services
cp security/security.service /etc/systemd/system/

systemctl daemon-reload
systemctl enable governor.service security.service
systemctl start governor.service security.service

    <h3>Cost Optimization for DigitalOcean</h3>
    <div class="note">
        <p>GitHub Education Pack gives you $200 credit for 12 months. Here's how to optimize costs:</p>
        <ul>
            <li>Start with smallest viable droplet (1GB RAM, $4/month)</li>
            <li>Use swap space if memory gets tight:
                <pre>sudo fallocate -l 1G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab</pre>
            </li>
            <li>Enable scheduled power-off during inactive periods (if applicable):
                <pre># Add cron job to shut down at 2 AM
echo "0 2 * * * /sbin/shutdown -h now" | sudo tee -a /etc/crontab</pre>
            </li>
            <li>Create snapshots instead of keeping droplets running when not in use</li>
            <li>Monitor usage with the watchdog service to prevent surprises</li>
        </ul>
    </div>

    <h2 id="security">6. Security Implementation</h2>
    
    <h3>Security Enforcement Agent (SEA)</h3>
    <p>The SEA agent provides comprehensive security monitoring and enforcement:</p>
    <ul>
        <li>File permission hardening</li>
        <li>Cron job backdoor detection</li>
        <li>Sudoers configuration validation</li>
        <li>Sensitive file monitoring</li>
        <li>Bash history sanitization</li>
        <li>Intrusion detection and alerting</li>
    </ul>
    
    <h3>Security Validation</h3>
    <pre>
# Check SEA agent status
systemctl status security.service

# Manually run security check
./security/sea_agent.sh --scan

# View security logs
cat $HOME/.assistant/security/sea_*.log

# Test file permission enforcement
chmod 777 ~/.ssh/id_rsa  # This should trigger SEA to fix it
sleep 10
stat -c %a ~/.ssh/id_rsa  # Should show 600
    </pre>
    
    <div class="important">
        <h4>Important Security Notes</h4>
        <ul>
            <li>Never expose your .env file with sensitive tokens</li>
            <li>Periodically review ~/.assistant/security/ logs</li>
            <li>Run the security audit procedure monthly:
                <pre>./security/sea_agent.sh --audit > security_audit.txt</pre>
            </li>
            <li>Ensure SSH keys are properly protected (600 permissions)</li>
            <li>Regularly update the system:
                <pre>./bootstrap/bootstrap.sh --update</pre>
            </li>
        </ul>
    </div>
